## Appris

- Le **DHT11** est utilisé dans le projet pour la mesure des paramètres météorologiques.
- L'**écran OLED** permet d'afficher les informations mesurées.
- L'**ESP32** constitue la carte de commande du système.
- Le projet permet de mettre en relation **capteurs, carte de commande et affichage**.
